Jede Nachricht nutzt ein frisches, per Ed25519 signiertes Ephemeral- X25519-Schlüsselpaar (ähnlich X3DH) statt direkt den Langzeit-Key — ein später gestohlener Langzeit-Key entschlüsselt damit keine bereits verschickten Nachrichten (Forward Secrecy gegen Sender-Kompromittierung; volle Double-Ratchet-Sicherheit ist ein offener Punkt, siehe README Fallstrick Nr. 1). Transport läuft über den öffentlichen Test-Broker test.mosquitto.org als Platzhalter für den echten "blinden" Relay-Server (backend/src/main.rs) — Inhalte bleiben E2EE-verschlüsselt, aber Topic-Namen/Zeitpunkte sind auf diesem öffentlichen Broker für Dritte einsehbar. Identitäts-Keys liegen zum Testen im localStorage dieses Browsers (Klartext) — siehe die nativen Referenzdateien für die gehärtete Keychain/Keystore-Variante.
